# 日々の余白 — 毎日の予定帳

やることと使える時間から、休憩と余白のある一日を組み立てるWebアプリです。インストールやログインは不要です。

## 開く

`index.html` をブラウザで開きます。同じフォルダーに `style.css`、`scheduler.js`、`pomodoro.js`、`app.js` を置いてください。インターネット接続は必要ありません。

プレビュー用のローカルサーバーを使う場合：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

`http://127.0.0.1:8765` をブラウザで開きます。終了はターミナルで Ctrl+C を押します。

## 使い方

- 「使える時間」を設定すると、優先度順に予定を自動で組みます。重複した時間帯はまとめて計算します。
- タスク名を入力して Enter を押すと、30分の「やりたいこと」を追加します。詳細な追加は「タスクを追加」またはキーボードの N です。
- タスク名か鉛筆ボタンから、時間・優先度・期限・繰り返しを編集できます。
- 完了ボタンを押しても、その日のタイムラインに予定は残ります。繰り返しの完了は日付ごとに記録されます。
- 矢印でタスクの順番を変更できます。「自動の順番に戻す」で優先度順へ戻せます。
- 入りきらない分は翌日に回せます。繰り返しタスクはその日の残りを外し、翌日は通常の所要時間で再登場します。
- 週や日付を切り替えて、日ごとに時間帯を設定できます。通常の未完了タスクは翌日以降にも表示されます。
- 完了したタスクの編集画面で実際の所要時間を記録すると、同じ名前のタスクの次回の見積もりに直近5回分の平均を反映します。
- データメニューからJSONのバックアップを保存・復元できます。復元内容を確認してから置き換えます。
- ポモドーロタイマーは25分集中・5分休憩・15分の長い休憩が初期設定です。集中4回ごとに長い休憩を案内します。時間は設定画面で変更できます。
- タイマーの開始・一時停止・再開・リセットができます。取り組むタスクは任意で選べます。終了してもタスクは自動で完了にしません。
- タイマーの残り時間は終了時刻から計算します。別タブから戻ったときや再読み込み後も引き継ぎます。次の集中や休憩は手動で開始します。
- 終了音は開始ボタンを押したあとに有効になります。タブやブラウザを閉じている間は音を鳴らせません。再読み込み後、音が出ない場合は「終了音」を一度オフ・オンしてください。

## 保存とプライバシー

予定はブラウザの localStorage（`sched.v2`）に保存します。外部へのデータ送信、アクセス解析、外部フォント、AI APIの呼び出しはありません。通信先を禁止するContent Security Policyも設定しています。

旧版の `sched.v1` が同じ保存場所にあれば読み込みます。旧版のキーは削除・上書きしません。元の画面は `index.original.html` に残しています。

ファイルを直接開いた場合の保存領域はブラウザによって異なります。同じブラウザでも、ファイルを移動したり、別のURLやポートで開くと保存データが見えないことがあります。変更前にバックアップを取ってください。旧版を直接開いていた場合は、旧ファイルのコピーでは保存領域が違う可能性があります。

保存内容は暗号化されません。同じ端末・ブラウザを使える人には閲覧できる場合があります。ブラウザのデータを削除すると予定も消えるため、定期的にJSONを保存してください。ファイル名や予定内容はバックアップにも含まれます。

このサイトの保存方式と、制作に使うCodex／ChatGPTのデータ処理は別です。

タイマーの設定・状態・集中回数は同じブラウザ内の `sched.pomodoro.v1` に別途保存します。予定用JSONバックアップには含まれません。

`.gitignore` で、すべてのディレクトリの `*.json`、ローカルの `preview/`、元の画面の `index.original.html` をGitの新規追跡から除外しています。すでにコミットしたファイルや、GitHubの画面から直接アップロードするファイルには `.gitignore` は適用されません。個人の予定バックアップはアップロードしないでください。

## 動作確認

Node.jsがある環境で実行します。追加パッケージは不要です。

```powershell
node --test tests/scheduler.test.js tests/pomodoro.test.js
```

予定の優先度、時間帯の重複、休憩、持ち越し、曜日、繰り返しの完了履歴、旧データの引き継ぎと、タイマーの一時停止・再開・復元・終了回数を検証します。

## GitHub Pagesへ置く場合

`index.html`、`style.css`、`scheduler.js`、`pomodoro.js`、`app.js` を公開用リポジトリに配置し、Settings → Pagesで公開ブランチを選びます。サイトのファイルが公開されます。予定データは閲覧した人のブラウザに保存され、サイトにはアップロードされません。

今回の作業では外部公開は行っていません。
